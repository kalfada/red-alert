# Changesets

Every change that affects users ships with a changeset. Run `npx changeset`, pick the bump, and describe the change in one line.

| Bump    | When (while < 1.0.0)                              |
| ------- | ------------------------------------------------- |
| `patch` | bug fix, perf, dependency/security update         |
| `minor` | new feature, removed or changed API/behaviour     |

The release flow is described in the root `README.md`.
